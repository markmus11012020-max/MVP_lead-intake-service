# Lead Intake Service (MVP)

Прототип сервиса для приёма и логирования заявок (лидов) с валидацией данных и сохранением в SQLite.

## Быстрый запуск (за 5 минут)

### 1. Подготовка окружения
Убедитесь, что у вас установлен Python 3.10+. Откройте терминал в папке проекта и выполните:

```bash
# Создание виртуального окружения
python -m venv venv

# Активация окружения (Windows PowerShell)
.\venv\Scripts\Activate.ps1

# Установка всех зависимостей
pip install -r requirements.txt
```

### 2. Запуск сервера
Запустите скрипт приложения:
```bash
python main.py
```
После запуска интерактивная документация Swagger UI будет доступна по адресу:  
👉 **http://127.0.0**

---

## Проверка работы (Пример запроса)

### Успешный запрос (POST /lead)
Отправьте через Swagger UI или любой HTTP-клиент (Postman, cURL) следующий JSON:
```json
{
  "name": "Галя",
  "contact": "+79991234567",
  "source": "Telegram-бот",
  "comment": "Интересуется разработкой MVP"
}
```
**Ответ сервера (HTTP 200):** Возвращает статус `"ok"`, сгенерированный ID и временную метку.

### Тест надежности (Валидация - HTTP 400)
Если отправить запрос без обязательного поля `contact` или с некорректным форматом (не телефон и не email):
```json
{
  "name": "Тест",
  "source": "Сайт"
}
```
**Ответ сервера (HTTP 400):** Сервер вернет понятную ошибку на русском языке.

## Где искать данные и логи?
* **База данных SQLite:** Файл `leads.db` создается автоматически в корне проекта. Посмотреть таблицы можно через **DBeaver** или *DB Browser for SQLite*.
* **Логи приложения:** 
  * `app.log` — технические логи работы сервера и критические ошибки (включая симуляцию HTTP 500 при падении БД).
  * `events.log` — бизнес-логи (фиксация ID каждого успешно созданного лида).
